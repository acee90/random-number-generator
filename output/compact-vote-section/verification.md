# 투표 영역 경계와 빈 공간 축소

관련 https://github.com/acee90/random-number-generator/issues/69 · 상위 #7 · 선행 PR70/71

- 집계 영역/양 팀 사이/다음 게임 위 구분선을 제거하고 버튼 자체 테두리는 유지했습니다.
- 화면 높이에 맞추던 결과 최소 높이, 사용하지 않는 결과 grid 행/간격, 집계 칸 최소 높이를 제거했습니다. 제목/버튼/목록/다음 행동은 콘텐츠 순서대로 필요한 높이만 사용합니다.
- 빈 목록은 한 명의 투표 행 높이만 확보해 첫 투표 전후 버튼과 영역이 튀지 않도록 했습니다. 이후 인원이 늘면 콘텐츠에 따라 확장합니다. 색/hover/선택/키보드/투표 정책 변경 없음.
-320px의 긴 자기 이름이 목록 열을 늘려 반응 시간을 자르던 문제는 목록 track을 minmax(0,1fr)로 바꿔 해결했습니다.

로컬 확인:
- 실제 브라우저320/597/1280px,0→1표·7명·29명/두 자리 집계·긴 이름·선택/키보드 확인.0→1표에서 집계 영역184px, 두 버튼518×88px와 top468.73px 동일(1280px CORE 예제).
- 집계/fieldset 테두리0px, 결과 min-height:auto. 좁은29인 목록의 scrollWidth=clientWidth=116px(양 열), 가로 잘림 없음.
- 실제 solo 긴 이름 결과1280px 영향 확인. solo320px은 별도로 확인하지 않았습니다.
- 기존 관련42개 테스트/3파일·TypeScript·Biome·앱/Storybook 빌드 통과. CSS/배치 변경으로 구현을 복제하는 테스트는 추가하지 않았습니다.
- 실제 모바일 기기/가상키보드·RTL·200% 브라우저 확대·OS 설정 변경·느린 모션은 미검증. 운영 배포는 이슈 #69에서 별도 기록합니다.
