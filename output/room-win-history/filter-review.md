# 당첨 내역의 조회 범위

룰렛과 슬롯머신의 당첨 내역은 현재 후보로 뽑은 결과부터 보여 준다. 이전 기록이 있을 때 제목 옆에 **이전 게임 포함** 체크박스가 나타난다. 체크하면 이전 당첨과 후보 변경 행이 같은 목록에 최신순으로 들어간다. [320px 기본 화면](current-slot-320.png) · [이전 게임 포함](all-slot-320.png)

## 범위와 근거

기존 탭과 네이티브 체크박스 시안을 Chrome에서 비교한 뒤, shadcn/ui 대화상자와 두 게임의 PixiJS 캔버스에 체크박스를 적용했다. 필터 조작 영역은 높이 44px이며 레이블 전체를 눌러 전환할 수 있다. [변경 전 탭](tabs-before-320.png) · [체크박스 시안](checkbox-preview-320.png) · [프로젝트 지침](../../AGENTS.md) · [관련 이슈](https://github.com/acee90/random-number-generator/issues/102)

| 검토 영역 | 확인한 상태 | 결과 |
| --- | --- | --- |
| 접근성 | 레이블 클릭과 Space로 전환, Escape로 닫기, Chrome 접근성 트리의 이름과 체크 상태 확인 | 상세 기록에서 돌아오면 같은 행에 포커스가 복귀하고 선택도 유지된다 |
| 배치 | 320·597·1150px에서 제목, 필터, 닫기 버튼의 좌표 및 창 크기 측정 | 세 행 기준 창 높이가 37px 줄었고 필터를 전환해도 크기와 중심이 유지됐다 |
| 문구 | 첫 추첨 후 두 탭의 행이 같고, 후보 변경 후에는 현재 1행이 전체 3행에 그대로 포함되는 것을 확인 | ‘이전 게임 포함’이 무엇이 추가되는지 설명한다 |
| 글꼴 | 당첨 이름은 15px·700, 보조 정보는 12px·400. 긴 후보 이름과 변경 문구의 줄바꿈 확인 | 두 시안 모두 좁은 화면에서 가로 넘침 없음 |
| 색상 | 실제 종이색 배경에서 이름과 보조 정보의 대비 측정. 눌림 배경은 캔버스 픽셀로 확인 | 이름 10.08:1, 보조 정보 5.82:1. 눌렀을 때 보조 정보는 7.75:1로 수정 |
| UI 상태 | 빈 목록, 긴 목록, 체크·해제, 호버·눌림, 키보드 포커스, 강제 색상 모드 | 두 캔버스에서 체크 표시와 포커스 테두리를 확인했다. 강제 색상 모드에서는 네이티브 체크박스로 조작했다 |

## 검증

| 화면 너비 | 창 너비 | 변경 전 탭의 창 높이 | 적용된 체크박스의 창 높이 |
| --- | --- | --- | --- |
| 320px | 278px | 299px | 262px |
| 597px | 416px | 299px | 262px |
| 1150px | 416px | 299px | 262px |

공유 방에서 방장이 룰렛을 돌린 뒤 김치찌개를 된장찌개로 바꾸고 슬롯머신을 돌렸다. 방장과 재접속한 참가자 모두 기본 목록에서 현재 당첨 1행을 봤고, 체크하면 두 당첨 사이에 후보 변경이 보였다. 이전 기록이 없는 방에서는 체크박스가 숨겨졌다. 보드에서 당첨 내역을 다시 열면 기본 목록으로 돌아온다. [597px 슬롯머신](all-slot-597.png) · [1150px 룰렛](roulette-history-1150.png)

`npm run check:roulette -- http://127.0.0.1:4191`와 `npm run check:slot -- http://127.0.0.1:4191`로 실제 게임 화면을 검증했다. 52건의 당첨을 넣은 개인 방에서는 목록 스크롤, 상세 행 포커스 복귀, 200% CSS 확대, RTL과 강제 색상 모드도 확인했다. [긴 목록](many-slot-597.png)

Chrome 접근성 트리에서 체크 상태를 확인했고, 두 캔버스에서 배경·체크 표시·키보드 포커스의 픽셀을 확인했다. VoiceOver 실기 낭독은 별도로 검증하지 않았다.
