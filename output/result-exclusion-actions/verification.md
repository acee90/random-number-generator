# 결과에서 중복 제외·보조 행동 정리

관련 이슈: https://github.com/acee90/random-number-generator/issues/65
로드맵: https://github.com/acee90/random-number-generator/issues/7

2026-11-17 로컬 검증 기록입니다. PR·머지·운영 배포 상태는 이슈 #65에서 관리합니다.

- 결과에서 ON이면 현재 당첨 후보를 즉시 제외에 추가합니다. 초기화 뒤 OFF→ON도 복원하며 같은 후보/메타데이터를 중복 추가하지 않습니다. 회차 원본·확률·표·기록·drawCount는 변경하지 않습니다.
- solo와 실제 멀티 서버, Storybook이 같은 setRoomExcludeDrawn을 사용합니다. 추첨 중 제외 결과를 먼저 표시하지 않는 공개 projection도 공유합니다.
- 기록 목록에서 복사와 별도 행동 줄을 제거했습니다. 내용 오른쪽44px ghost 화살표로 상세를 열며, 제목에 초기 포커스·키보드 Tab/Enter·상세 닫기 후 원래 버튼 복귀를 확인했습니다. 상세 기록의 전체 내보내기·초대 링크는 별도 기능입니다.
- 초기화는 스위치 옆44px ghost 아이콘으로 이동. 비어 있을 때는 비활성으로 위치를 유지하고, 참가자에게는 숨깁니다. 확인창·원본/현재 결과 보존은 유지합니다.
- 현재 결과의 후보 이름은 제외 목록에서 반복하지 않고 ‘이번 당첨 포함’으로 요약합니다. 다음 게임 대기에서는 기존 제외 후보 이름을 다시 식별할 수 있습니다.

## 검증

- 전체1,489개/51파일 테스트(workers4), 타입·변경 코드 Biome·앱/Storybook 빌드 통과.
- 서버: 참가자 거부, 저장 실패 rollback, 같은 명령 재시도/중복, 결과/기록 불변, 현재 당첨 포함과 다음 게임 제외 검사.
- 실제 localhost HTTP/WS43개 검사 통과. 시험 방1개·추첨2회, 방 명시 종료·모든 소켓 종료. 추가한 세 검사는 참가자 거부, 초기화 후 재활성화의3인 동기화/기록 불변, 다음 게임 제외 유지입니다.
- 실제 브라우저597/320/1280px에서 결과 후 OFF→ON(후보2→1), 초기화(제외0)→OFF→ON(제외1), 다음 대기에서 다른 후보1개만 남음, 현재 이름 중복 제거·복사 없는 기록 목록·ghost 초기화 위치를 확인했습니다. 가로넘침 없음.
- 실제 모바일 기기·가상키보드·RTL·느리게 재생한 모션은 이번 수동 검증 범위 밖입니다. 새 모션/공통 기본 스타일을 추가하지 않았습니다.
