# 결과 투표 통합

관련 이슈: https://github.com/acee90/random-number-generator/issues/69
상위: https://github.com/acee90/random-number-generator/issues/7

- 별도 actions 렌더와 모바일 투표 후 접기/강제 초점 이동 제거. 실시간 현황 헤더의 outline Button에서 투표합니다. count/내 선택/랭킹/낙관적 전송·실패 복귀/읽기 전용 기록 유지.
- aria-disabled와 동작 가드로 재투표를 차단하고 같은 버튼에 포커스를 유지합니다. 선택은 체크와 내 선택으로도 표시합니다.
- OFF는 실제 후보에서 제외하지 않는 기존 정책을 유지하면서, 최신 당첨 저장값을 제외 목록으로 표시하지 않습니다. 초기화도 비활성. ON의 즉시 현재 당첨 추가는 보존합니다.
- 수동 애니메이션 끄기·켜기 기능/버튼/CSS 제거. OS reduced-motion은 유지합니다.
- 정확한 회차 표기를 N회차 당첨으로 변경. 불확실한 과거 기록 번호는 구분합니다.

검증: 전체1,490개/51파일 테스트·TypeScript·Biome·앱/Storybook 빌드 통과. 투표 전송/ACK/실패/재연결·자격·읽기 전용·동일 버튼 초점·내역 OFF 숨김/ON 복귀 회귀 포함.

실제 localhost320/597/1280px: 긴 이름·투표 버튼 Enter→실제 ACK/내 선택1명·후속 선택 차단, OFF 다음 게임에도 동일 후보 유지·제외 목록 숨김, 실제4초 회전 중 수동 애니메이션 버튼 없음 확인.597px 두 버튼은 투표 전후 각각257.5/256.5×88px로 동일. 가로 넘침 없음. 대표 화면 첨부.

실제 모바일 가상키보드·RTL·200% 확대·포인터 hover·OS 설정 전환·느린 모션은 미검증. 운영 반영은 이슈 #69에서 별도 기록합니다.
